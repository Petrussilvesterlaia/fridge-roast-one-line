One line, at most 200 characters, roasting a smart fridge — its 3 a.m. firmware update, its camera's opinion of the milk, and an ice maker that now demands a password for every cube:

> My smart fridge pushed a firmware update at 3 a.m., then its camera flagged my milk as 'suspicious' — now the ice maker demands a password for every cube.

`main.py` writes that single line to `/output/entry.txt`, validated (one non-empty line, at most 200 characters) and byte-identical on every run.

## Run it

```sh
python3 main.py
```
